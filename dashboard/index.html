How this works

SyntraceAI breaks your code on purpose to find out what your tests don't notice. It runs entirely on this machine - no account, no upload, no API cost.

01

Point it at a project

Any local Python project with a test suite. The bundled demo app is already selected below.

02

Run the campaign

It injects 50 small bugs - flipped comparisons, shifted thresholds, corrupted prompts - and runs your suite against every one in a sandbox. About 10 seconds.

03

Read the gap

Coverage tells you which lines ran. The score tells you how many bugs your tests actually caught. The difference is what coverage was hiding.

04

Keep the tests it writes

For every bug that slipped through, it synthesizes a test that provably catches it, written into your project's tests folder.

You can reopen this any time with the ? button in the header.

Your code never leaves this machine. Layout other than app/ + tests/? Drop a syntrace_target.json in the project naming your source_package and tests_dir.
