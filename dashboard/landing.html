The loop

Four moves, every campaign.

One command. Every number in the report comes from a real, seeded, reproducible run.

01

Inject

Seven AST operator families flip >= to >, + to -, negate branches, nudge boundary constants. Twelve prompt perturbations strip roles, rename schema keys, corrupt delimiters.

02

Isolate

Every bug runs against your suite in its own sandboxed copy of the project - parallel and timeout-guarded. Runaway mutants get killed, not your machine.

03

Score

Killed vs. survived over a frozen bank. The mutation score is the number your line-coverage report was hiding: how many real behavior changes your assertions actually notice.

04

Heal

For each survivor, differential probing finds an input where original and mutant disagree, then synthesizes a hardened assertion - re-verified before it is written, never guessed.

Engine

Seven operators. Twelve perturbations. One honest score.

Built as a dual-solution benchmark: the same bug bank audits a standard coverage.py baseline and the SyntraceAI campaign.

enumerate_mutants() 38 mutants

AST Mutation Engine

Arithmetic, comparison, boolean, condition-negation, constant, boundary and return-value operators. Every mutant is compile-validated; provably-equivalent clamp swaps are excluded so the bank never lies.

enumerate_perturbations() 12 attacks

Prompt Perturbation Fleet

Role stripping, JSON-only directive removal, schema key renames, zero-width whitespace, few-shot drop - surfacing hallucination paths your happy-path tests never touch.

evaluate_many() parallel

Sandboxed Execution

Fresh project copy per mutant, parallel workers, hard timeouts. Exit codes map to killed / survived / timeout / error - loud failures count, silence never does.

heal_survivors() verified

Differential Auto-Healing

Subprocess probes over boundary-aware inputs - type-hint pools, harvested literals, anchored sweeps, the module's own API. Only a re-verified discriminating input becomes a test.

Deterministic

Same seed → identical bank, identical scores, on any machine, at any parallelism. Reports are byte-stable.

Honest

Equivalent mutants are reported, never hidden. No verified input, no test. Timeouts and errors are labeled, not laundered.

Validated

Same engine, unchanged, on humanize 4.16.0: 94.7% on the frozen bank, and 12 auto-healed tests the library never had.
