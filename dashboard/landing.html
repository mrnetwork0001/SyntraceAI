An adversary in four moves

One command runs the whole campaign. Every number in the report comes from a real, seeded, reproducible run.

Inject

Seven AST operator families flip >= to >, + to -, negate branches, nudge boundary constants. Twelve prompt perturbations strip roles, rename schema keys, corrupt delimiters.

Isolate

Every bug runs against your suite in its own sandboxed copy of the project — parallel, timeout-guarded, resource-capped. Runaway mutants get killed, not your machine.

Score

Killed vs. survived. The mutation score is the number your line-coverage report was hiding: how many real behavior changes your assertions actually notice.

Heal

For each survivor, differential input search finds an input where original and mutant disagree — then synthesizes a hardened assertion test pinning the correct behavior. Verified, never guessed.

What's in the engine

Built as a dual-solution benchmark: the same 50-bug bank audits a standard coverage.py baseline and the SyntraceAI campaign.

🧬

AST Mutation Engine

Arithmetic, comparison, boolean, condition-negation, constant, boundary and return-value operators. Every mutant is compile-validated before it ships to a sandbox.

🗣️

Prompt Perturbation Fleet

Twelve attacks on the system prompt — role stripping, JSON-only directive removal, schema key renames, zero-width whitespace — surfacing silent hallucination paths your happy-path tests never touch.

📦

Sandboxed Execution

Fresh project copy per mutant, parallel workers, hard timeouts. Exit codes map to killed / survived / timeout / error — loud failures count as detections, silence never does.

🩹

Differential Auto-Healing

Subprocess probes evaluate original vs. mutant over boundary-aware generated inputs. Only a verified discriminating input becomes a test; equivalent mutants are reported honestly.

🛰️

Trajectory Logging

Every campaign step — instructions, tool commands, outputs, human checkpoints — captured as agent trajectory JSON, ready for evaluation platforms like micro1.

🎛️

Mission Control

A local dashboard to launch campaigns, stream the engine log live, and explore scores, survivors and healed tests — plus JSON and self-contained HTML reports for CI.
